# Northbridge Molecular Diagnostics Audit

[Open the interactive Northbridge case](https://ropazimunya.github.io/northbridge-molecular-diagnostics-audit/)

Review three simulated laboratory records and decide what to check when a respiratory PCR report has already been transmitted and its release approval fields are blank.

Under **Supporting evidence**, the case includes the Stage 3 draft internal audit report and the working paper covering all 18 checkpoints. The case, records, and procedures are fictional.
